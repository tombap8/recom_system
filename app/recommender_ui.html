🎬 콘텐츠 기반 영화 추천 시스템

장르 유사도(코사인 유사도) + 가중 평점(IMDB Weighted Rating)을 활용한 TMDB 영화 추천 데모

⚠️ 데이터(data.json)를 불러오지 못했습니다.
브라우저에서 file:// 로 직접 열면 보안 정책(CORS) 때문에 로딩이 막힐 수 있습니다.
로컬에서 확인하려면 app 폴더에서 python -m http.server 실행 후 http://localhost:8000/recommender_ui.html 로 접속해보세요.
